# RACS Projects — MEP Engineering & Contracting Website

A modern, high-end, responsive corporate website built for **RACS Projects**, a premier Mechanical, Electrical, and Plumbing (MEP) contracting company based in Hyderabad, India.

---

## Key Features

- **5 Dedicated Pages**:
  - `index.html` — Hero with dark overlay, Intro split layout, 5 Services grid, 4 Value proposition cards, Featured projects preview, Animated stats counter, 5-Step execution roadmap, CTA banner.
  - `about.html` — Who We Are, Mission & Vision, 5 Core Values cards, Workflow lifecycle timeline, ISO/NFPA/ASHRAE certification placeholders.
  - `services.html` — Alternating split-layout showcases for all 5 core disciplines with detailed scopes of work and benefits.
  - `projects.html` — Interactive JavaScript filterable portfolio (Commercial, Residential, Industrial, Hospitality, Healthcare, Infrastructure).
  - `contact.html` — Comprehensive contact form with real-time JavaScript validation, editable contact details, and a responsive Google Maps embed placeholder.
- **Strict Service Order Maintained Throughout**:
  1. **Fire Fighting Systems**
  2. **HVAC & Ventilation**
  3. **Electrical Systems**
  4. **Plumbing**
  5. **BMS & ELV Systems**
- **Clean Tech Stack**: HTML5, Bootstrap 5.3.3, CSS3, Vanilla JavaScript, Font Awesome 6.5.1, and Google Fonts (Poppins & Inter). No backend framework required.
- **Fully Responsive**: Optimized for display on desktop (1920px), laptop (1440px/1200px), tablet (992px/768px), and mobile (576px/375px) viewports with sticky animated navbar.

## How to Customize Placeholder Details

1. **Contact Details**: In `contact.html` & the footers of all pages, update `+91 XXXXX XXXXX` and `info@racsprojects.com` with actual phone numbers and email addresses.
2. **Google Maps Embed**: In `contact.html`, locate the commented Google Maps section and replace the iframe source URL with your specific business address location URL.
3. **Certifications**: In `about.html`, replace or customize the standard ISO, NFPA, and ASHRAE placeholder badges with actual company certification logos.
